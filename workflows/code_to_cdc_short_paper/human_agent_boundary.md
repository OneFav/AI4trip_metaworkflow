# Human-Agent Boundary

## Human Does

1. 定义论文主问题与贡献主线，约束可宣称范围。
2. 在 checkpoint 审核补强实验计划，决定预算与时间上限。
3. 对结论风险句进行最终裁剪，确认投稿策略。

## Agent Does

1. 扫描代码结构、配置与日志，抽取主张与实现证据。
2. 执行补强实验，产出结果表、统计报告与图表资产。
3. 生成 CDC 短文草稿、图表映射、合规检查清单。

## Human-Agent Collaboration

1. Checkpoint A：共同决定执行哪些严谨性补强项。
2. Checkpoint B：共同决定短文是否进入最终投稿稿。
3. 共同处理“结果不显著但有研究价值”的叙事策略。

## Trip Compatibility Note

1. 需要高认知判断的任务留给 Human。
2. 可异步批量执行的任务交给 Agent 后台推进。
