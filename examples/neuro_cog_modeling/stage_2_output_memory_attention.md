# Stage 2 Output: 记忆痕迹 × 注意力机制 候选模型

## 目标
在同一数学框架下统一解释：
1) 记忆痕迹随时间衰减与重激活
2) 注意力在任务需求和外界干扰下的动态分配

## 参数字典
- M_t: 目标项目的记忆痕迹强度
- A_t: 分配给该项目的注意力权重
- I_t: 外部干扰强度
- u_t: 主动刷新/复述控制输入
- lambda: 自然衰减系数
- beta: 注意力对维持痕迹的增益
- eta: 干扰对注意力的夺取强度

## 候选模型 1：注意力门控的记忆痕迹 ODE（Mechanistic Baseline）
### 形式
dM/dt = -lambda * M_t + beta * A_t * u_t

dA/dt = rho * (D_t - A_t) - eta * I_t * A_t

其中 D_t 表示任务需求驱动（top-down）。

### 可解释性
- 当 I_t 升高时，A_t 下降，从而 M_t 维持项变弱，出现“注意力被夺走导致记忆崩塌”。
- 当 u_t>0 且 A_t 足够高时，记忆可被刷新，解释 rehearsal 效应。

### 生物/心理合理性
- 与“有限注意资源 + 记忆刷新”机制一致。
- 适合行为层时间序列或短时任务连续跟踪数据。

## 候选模型 2：双层 DDM（选择注意 + 记忆读出）
### 形式
上层（注意选择）:

dX_a = v_a(M_t, I_t) dt + sigma_a dW_t

a_t = 1 if X_a reaches +theta_a else 0

下层（记忆读出决策）:

dX_m = v_m(M_t, a_t) dt + sigma_m dW_t

RT 与正确率由 X_m 的边界到达时间决定。

### 可解释性
- 注意力先决定“是否进入目标通道”，再决定记忆证据累计质量。
- 能自然映射到 RT 分布与准确率联合拟合。

### 生物/心理合理性
- 与经典 DDM 兼容，便于接入 HDDM。
- 对二选一/多选一任务非常友好。

## 候选模型 3：贝叶斯状态空间模型（Latent Attention-Memory Coupling）
### 形式
隐变量状态：

M_t ~ Normal(alpha_M * M_{t-1} + beta_M * A_{t-1} - gamma_M * I_t, sigma_M)

A_t ~ Normal(alpha_A * A_{t-1} + delta_A * D_t - eta_A * I_t, sigma_A)

观测方程：

y_t^{acc} ~ Bernoulli(sigmoid(w1*M_t + w2*A_t))

y_t^{rt} ~ LogNormal(mu0 - c1*M_t - c2*A_t, sigma_rt)

### 可解释性
- 把注意-记忆耦合建成可追踪的隐状态。
- 能吸收被试间差异（层级先验），适合 PyMC。

### 生物/心理合理性
- 支持不完全观测和噪声数据。
- 适合复杂任务、跨条件比较、个体差异分析。

## 三模型比较
- ODE: 参数少、可解释性高、实现快；但对 RT 分布刻画弱。
- 双层 DDM: 与决策任务最贴合，易与 HDDM对接；但对连续注意状态表达有限。
- 贝叶斯状态空间: 统一能力最强、可纳入多观测；但计算成本高。

## 推荐框架
推荐 **候选模型 3（贝叶斯状态空间）** 作为主线，候选模型 2 作为对照基线。

原因：
1) 你的目标是“统一解释”，状态空间模型对两个机制的耦合表达更完整。
2) 后续 Stage 4 需要可拟合人类数据，PyMC 层级建模更适配个体差异。
3) 可在 Stage 3 中更自然地接收反例并局部改结构（例如增加疲劳项 F_t）。

## 进入 Stage 3 前的建议反例接口
建议你在 Stage 3 至少提出以下反例方向：
1) 高干扰下仍维持高记忆表现的专家被试
2) 注意力指标下降但记忆准确率不降的条件
3) 短时高负荷后出现恢复性反弹（非单调衰减）
